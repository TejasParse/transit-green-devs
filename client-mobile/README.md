# Client Mobile

This directory contains the Expo/React Native frontend for Ride Green Devs.

For the full project architecture, backend explanation, setup guide, and feature walkthrough, see the repository README:

- [`../README.md`](../README.md)

Useful local commands:

```bash
npm install
npm start
npm run lint
```

Primary review entry points:

- `app/(tabs)/index.tsx` for walk/bike/transit/drive comparison and route navigation simulation
- `app/(tabs)/leaderboard.tsx`
- `app/(tabs)/profile.tsx`
- `lib/google-places.ts`
- `lib/google-routes.ts`
- `lib/api.ts`
